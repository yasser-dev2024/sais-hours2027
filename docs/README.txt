صفحة سايس الخيل
================

صفحة دعائية مستقلة ومهيأة للنشر من مجلد /docs في GitHub Pages.
زر تحميل Android الوحيد يشير نسبيًا إلى:

./downloads/SaisAlkhail-v2.1.1-build22.apk

لا تُعدّل بيانات الإصدار والحجم والتاريخ يدويًا.
شغّل build_android_and_web.ps1 من جذر مشروع Flutter ليُعاد بناء APK
وتحديث الصفحة تلقائيًا.

يجب رفع ملف APK الوحيد الموجود داخل docs/downloads مع الصفحة، ولا يجوز استبداله بصفحة HTML
أو رابط file:/// أو مسار محلي من الكمبيوتر.
